# Subscription Tracker

Subscription Tracker is a personal project that I started to solve a real-life problem while improving my backend development skills.

Many online services require recurring payments, and sometimes subscriptions are paid through friends or family members living abroad. Keeping track of renewal dates, prices, payment history, and who paid for what can quickly become inconvenient.

The goal of this application is to keep subscription-related information in one place: active subscriptions, payment history, renewal dates, and other useful details.

This project is also an opportunity for me to deepen my knowledge of backend development with NestJS, TypeORM, authentication, REST APIs, and React on the frontend.

The current version is a basic working version of the application, covering the core functionality. Development and further improvements are temporarily paused while I focus on improving my French. I plan to return to the project afterwards and continue working on the features outlined in the roadmap below.

Subscription Tracker — Français

Subscription Tracker est un projet personnel que j'ai commencé afin de résoudre un problème concret tout en développant mes compétences en développement backend.

De nombreux services en ligne fonctionnent avec des abonnements récurrents. Il arrive que ces abonnements soient payés par des proches vivant à l'étranger, ce qui rend le suivi des paiements, des dates de renouvellement et de l'historique des transactions assez compliqué.

L'objectif de cette application est de regrouper les informations liées aux abonnements au même endroit : les abonnements actifs, l'historique des paiements, les dates de renouvellement et d'autres informations utiles.

Ce projet est également l'occasion d'approfondir mes connaissances en NestJS, TypeORM, l'authentification, les API REST ainsi que React pour la partie frontend.

La version actuelle est une première version fonctionnelle de l'application qui couvre les fonctionnalités principales. Le développement et les améliorations sont temporairement mis en pause afin que je puisse me concentrer sur l'amélioration de mon français. Je prévois de revenir ensuite sur ce projet afin de continuer à développer les fonctionnalités prévues dans la roadmap ci-dessous.
